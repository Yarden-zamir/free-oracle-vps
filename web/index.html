1Your part: the account

A script cannot do these steps. They need your card, your phone and a browser login.

  1. Sign up at signup.cloud.oracle.com. Use a password manager for the password. Click "Start my free trial". The trial gives $300 of credit for 30 days. The Always Free resources stay free after that.
  2. Pick the home region with care.

    🔴 You cannot change it later, and the free ARM server exists only in the home region.

    • Israel Central (Jerusalem): lowest latency from Israel. It has one data center only.
    • Sweden Central (Stockholm) or Spain Central (Madrid): less used, so free capacity is easier to get.
    • Germany Central (Frankfurt) or Netherlands Northwest (Amsterdam): good, but popular.
  3. Add your card and finish the signup. Wait for the email that says your account is ready.
  4. Turn on two-factor login. In the console, open your profile, then Security, then Enable multi-factor authentication.
  5. Install uv, the tool that runs the script. It also gets Python and the Oracle tools for you. On a Mac or Linux: 
    curl -LsSf https://astral.sh/uv/install.sh | sh

    On Windows, in PowerShell:

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  6. Log in from a new terminal: 
    uvx --from oci-cli oci setup bootstrap

    A browser opens. Log in there. In the terminal, enter your home region by name (for example il-jerusalem-1) or by its number in the list. Accept the defaults for the other prompts.

2Build the server

Run the script straight from this site. First check what it would do, without any change:

uv run https://free-oracle-vps.yarden-zamir.com/oracle-free-server.py --plan

Then build the server:

uv run https://free-oracle-vps.yarden-zamir.com/oracle-free-server.py

To keep a copy and read it first, download it, then run the local file:

curl -LsSfO https://free-oracle-vps.yarden-zamir.com/oracle-free-server.py
uv run oracle-free-server.py --plan

The script asks for an email for the cost alert. Then it does the rest, in this order:

  • Quotas that block every paid resource, and a 1 USD budget that emails you about any charge.
  • A network, a public subnet and Oracle's firewall rules.
  • The server. If Oracle has no free capacity, the script tries every data center again each minute. Press Ctrl+C to stop.
  • A reserved public IP address that never changes.
  • A Host oracle-vps entry in ~/.ssh/config, and the same ports opened in the server's own firewall.

Run it again at any time. It reuses what already exists.

3After the build

When the script ends, you have:

  • ✓A running server. Connect with ssh oracle-vps.
  • ✓A reserved public IP address. Point your domain at it.
  • ✓The free-tier-only quotas. They block every paid resource, also with a stolen login.
  • ✓The free-tier-guard budget. It emails you about any charge.

Last step: upgrade to Pay As You Go

In the Oracle console, open the menu (☰), then Billing & Cost Management, then Upgrade and Manage Payment. Pick Pay As You Go.

Why upgrade? On a free account, Oracle can stop a server that stays below 20% use for 7 days. After 30 days, a free account also loses everything that is not Always Free. Pay As You Go removes both risks. The quotas block every paid resource, so the upgrade alone does not cost money. Expect a temporary card hold of about $100. Oracle sends the email "your subscription(s) has been updated" when the upgrade is done.

4The catches

idle reclaim

Idle servers can go

On a free account, Oracle can stop a server that stays below 20% CPU, network and memory use for 7 days. Pay As You Go removes this.

account risk

Accounts can close

People report sudden closures of free accounts after fraud checks. Keep backups of important data outside Oracle.

ARM

ARM only

Most Linux software and Docker images run on ARM. Some old x86-only programs do not.

no promise

No uptime promise

Free resources have no guarantee and no support. Oracle can change the free limits.

traffic

Traffic over 10 TB

Outbound traffic is free up to 10 TB a month. More costs about $9 per TB. Quotas cannot block this. The budget alert tells you.

disk full

No free disk left

The server uses all 200 GB of free disk. The quotas block more disk. Oracle includes 5 free disk backups.

The real money risk is a stolen login. Attackers use stolen cloud logins to mine crypto on large servers. Two-factor login protects the console. The quotas block paid servers even with a stolen key. The key in ~/.oci/ lets any program on your computer manage your account. Delete the folder when you no longer need it.

5Help

The script says "no free capacity" for a long time

Free ARM capacity is often sold out in popular regions. Let the script run; it tries again each minute. Some people wait hours. The Pay As You Go upgrade usually makes capacity easier to get.

"Oracle still rejects the login"

A new login key takes a few minutes to work, and the script waits up to 2 minutes. If it still fails, run the login again:

uvx --from oci-cli oci setup bootstrap
My website does not load on port 80 or 443

Two firewalls must allow the port: Oracle's firewall and the server's own iptables rules. The script opens both. If you used --no-server-firewall, add the rules in /etc/iptables/rules.v4 above the final REJECT line. Oracle's Ubuntu images do not use ufw.

How do I remove everything?

In the Oracle console, terminate the server (Compute, Instances) and choose to delete its disk. Then delete the reserved IP, the network, the quota policy and the budget. Free resources cost nothing while they exist, so you can also keep them.

Does this work on Windows?

Yes. Install uv with the PowerShell command in step 5, then run the same commands. The server firewall step needs the OpenSSH client, which Windows 10 and 11 include. Nobody tested it on Windows yet; open an issue if it fails.
